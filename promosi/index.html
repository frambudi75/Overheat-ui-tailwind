DEPLOYMENT READY

Deploy landing page atau template admin ini ke server VPS Anda hanya dalam 1 menit.

AA

Deploy di aaPanel (Nginx / Apache)

  1. Buka menu Website ➔ Add Site di dashboard aaPanel.
  2. Upload seluruh isi folder ini ke direktori /www/wwwroot/domain-anda.com/.
  3. Aktifkan SSL Let's Encrypt dengan 1 klik. Selesai! Web langsung live.
🐳

Deploy dengan Docker Compose

Cukup jalankan satu perintah di terminal server VPS Anda:

docker compose up -d

Container Nginx Alpine super ringan langsung berjalan di port 8080.
